RanjitGo 📚✨
Smart English Learning Platform
Overview

RanjitGo is an all-in-one English learning app designed to make learning English simple, interactive, and enjoyable. The app provides video lectures, grammar lessons, stories, comic books, vocabulary practice, daily tasks, learning games, and Oxford & Cambridge level exam preparation for students and learners of all levels.

Whether you are a beginner or an advanced learner, RanjitGo helps improve your speaking, reading, writing, listening, and grammar skills with a modern and user-friendly experience.

📥 Installation

Clone the repository:

git clone https://github.com/QuantumCode001/RanjitGo.git

Go to the project folder:

cd RanjitGo

Install dependencies:

npm install

Run the development server:

npm run dev
